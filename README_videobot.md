# 📥 VideoBot — Telegram Video Downloader

> Скачивает видео и аудио с YouTube, Instagram, TikTok, Twitter/X и 1000+ сайтов прямо в Telegram

---

## ✨ Возможности

- 🎬 **Скачивание видео** — 360p / 480p / 720p / 1080p / максимальное качество
- 🎵 **Извлечение аудио в MP3** — 128k / 192k / 320k
- 🖼 **Превью с обложкой** — показывает название, автора, длительность и просмотры перед скачиванием
- 📦 **Автоматическое разбиение** — файлы больше 50 МБ нарезаются на части по 45 МБ автоматически
- 📋 **Очередь загрузок** — задачи выполняются по одной, не теряются
- 📊 **Прогресс-бар** — обновляется каждые 5% в реальном времени
- 🌍 **1000+ сайтов** — через yt-dlp: YouTube, Instagram, TikTok, Twitter/X, VK, Twitch и другие

## ⚙️ Установка

### 1. Клонируй репозиторий

```bash
git clone https://github.com/LAZERDIMA700GG/videobot.git
cd videobot
```

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

### 3. Установи FFmpeg (обязательно!)

Бот использует три исполняемых файла для конвертации и обработки медиа:

| Файл | Назначение |
|------|-----------|
| `ffmpeg.exe` | Конвертация, слияние видео+аудио дорожек |
| `ffprobe.exe` | Анализ медиафайлов |
| `ffplay.exe` | входит в комплект поставки |

**⬇️ Скачать всё одним архивом:** [ffmpeg.org/download.html](https://ffmpeg.org/download.html)

> Выбери свою платформу → раздел **"Windows Builds"** → скачай архив **"full_build"** — в нём будут все три файла сразу.

После скачивания распакуй архив и укажи путь до папки с `.exe` файлами в `bot.py`:

```python
FFMPEG_DIR = r"C:\путь\до\папки\с\ffmpeg"
```

### 4. Создай файл `.env`

```env
BOT_TOKEN=твой_токен_от_BotFather
```

### 5. Запусти бота

```bash
python bot.py
```

## 🔧 Конфигурация

В начале `bot.py` можно настроить:

```python
# Папка для временных файлов (удаляются после отправки)
DOWNLOADS_DIR = "downloads"

# Лимит Telegram для ботов (не менять без причины)
TG_MAX_SIZE = 50 * 1024 * 1024  # 50 МБ

# Путь к папке с ffmpeg.exe, ffprobe.exe, ffplay.exe
FFMPEG_DIR = r"C:\Users\...\ffmpeg"
```

## 🎮 Как пользоваться

```
1. Отправь боту ссылку на видео
        │
        ▼
2. Бот покажет превью: название, автор, длительность
        │
        ▼
3. Выбери формат: 🎬 Видео  или  🎵 Аудио (MP3)
        │
        ▼
4. Выбери качество
   Видео: 360p / 480p / 720p / 1080p / Максимальное
   Аудио: 128k / 192k / 320k
        │
        ▼
5. Получи файл прямо в чат
   (если > 50 МБ — придёт частями по 45 МБ)
```
